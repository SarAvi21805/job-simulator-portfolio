# 🧠 Job Simulator - Emotional Console 🌈

¡Bienvenidos a mi Cuartel Central! Este proyecto es un portafolio interactivo inspirado en la película *Inside Out* (Intensamente), diseñado para el desafío de Job Simulator.

## 🚀 Características
- **Navegación Emocional:** Explora mis proyectos filtrados por el "sentimiento" técnico que representan.
- **Isla de la Personalidad:** Conoce mi formación y pasiones (K-Pop, Anime, Desarrollo).
- **Manual de Sistemas:** Un vistazo a mis habilidades técnicas (Frontend, Backend, Low Level).
- **Interfaz Inmersiva:** Efectos visuales, sonidos y partículas que simulan la mente humana.

## 🛠️ Tecnologías
- HTML5 / CSS3 (Animaciones, Glassmorphism)
- JavaScript Vanilla (Lógica de estados y DOM)
- Git / GitHub (Control de versiones)
